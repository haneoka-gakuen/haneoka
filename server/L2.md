# 本地服务与采集 · L2

上级：[地图](../L1.md)。

## 职责与入口

[ranking-collector-official](ranking-collector-official/README.md) 是独立 Python 四服榜单采集器；配置式下载与校验 Master，生成活动目标，保存单曲／总榜观测，并提供只读新鲜度接口。Windows、Linux 和 macOS 共用 Python TLS／HTTP/2、进程锁与离线安装入口；日服匿名 Version 动态提供 CDN 密码，客户端用户名与解码参数由外置配置提供，catalog 与采样共用目录落库和换期检查。国际服通过官方 GetServerList 发现分区 CDN；[分区合同](ranking-collector-official/core/regions.py) 固定 API、凭据区服和协议描述，每个运行目录保存独立目录、换期水位及历史。

工具内部由 [HTTP/2 传输](ranking-collector-official/core/http2.py)、[跨平台进程锁](ranking-collector-official/core/process_lock.py)和[离线安装](ranking-collector-official/setup.py)分别负责官方请求、进程协调及固定依赖安装。

[账号池 CLI](ranking-collector-official/account-pool.mjs)兼容原 T62 SQLite/AES-GCM 私密注册表，管理 origin 绑定、启停、区域选择、租约与认证暂停；[有界查询](ranking-collector-official/core/pool_query.py)复用同服官方 Master 和 Python Sampler，导出公开单曲／总榜及私密云配置，不执行登录或注册。

[云端入口](ranking-collector-official/cloud.py)与[单轮适配器](ranking-collector-official/core/cloud_job.py)在独立 Cloudflare Container 中复用官方目录及请求协议；每轮通过获认证的 Worker 回调提交目录、请求检查点及观测，再由区域 Durable Object 调度并持久保存运行控制及固定白名单的失败阶段／状态码。临时目录只存本轮私有配置与回执，历史正文、游标和认证暂停由云端存储负责；容器本地 SQLite 不参与云端读写。

[按需读取](ranking-collector-official/core/demand.py)在同一轮次内补玩家资料与乐曲榜单，被拒绝时只结束本轮按需读取，不影响账号；[Arena 采样](ranking-collector-official/core/arena.py)按任务能力复用同一身份、版本及请求预算，优先补兴趣窗口，再采五个联赛；人口使用同服开放 LP 阈值、持久搜索提示与本轮边界复验，未完成不发布完整人数。缺少 Arena 能力的旧任务仍仅获取原三张活动表和活动榜单。

[存储](ranking-collector-official/core/history.py)在 SQLite 中原子绑定运行分区，拒绝跨服或混服历史；旧日服数据只读检查不迁移，写入时收录其分区身份。[只读接口](ranking-collector-official/core/api.py)按数据库及状态分区校验请求，错误分区 URL 不读取其他服历史。[分区合同](ranking-collector-official/core/regions.py)集中定义固定 API、同服凭据来源、协议描述和 CDN 发现规则。

[preview.ts](preview.ts) 启动本地 Node HTTP 服务，提供构建后的静态页面、release-backed 目录／媒体／Sonolus，以及受约束的供应方代理。[releaseWorkspace.ts](releaseWorkspace.ts) 解析本地 current 指针、release 身份和安全文件路径。

输入为构建输出、环境选择及授权的本地 release；输出为本地 HTTP 响应。服务会读文件、监听端口，并可向配置的供应方／Worker 发请求。缺 `current.json` 或本地资源时，源码克隆本身不能提供完整目录。

HTML 响应从同一构建目录的 `build.json` 注入更新基准；存储文档及共享脚本不携带冻结发布的全局身份。
`web` 是浏览器更新基准；有 `publication` 时，预览核对本地最终引用摘要。旧格式继续使用原 Web 基准。

这里与 [src/server](../src/server/L2-2.md) 的构建期 SSR、[worker](../worker/L2.md) 的生产绑定分别维护。代理的认证／请求头边界须保留，不能把本地预览视为完整生产替身。

改资源身份、分片与地址核对 [共享契约](../scripts/core/L2-2.md)、Worker 和构建读取。启动和验证命令见 [开发导航](../docs/DEV_GUIDE.md)。
