# 站点国际化 · L2-2

上级：[地图](../L2.md)。

## 职责与入口

站点层组织消息命名空间、服务端种子、浏览器加载、语言协商和 DOM 更新；基础 locale／消息处理由 [i18n 包](../../packages/i18n/README.md) 提供。

| 入口 | 所有权 |
| --- | --- |
| [server.ts](server.ts) | 从正式消息目录构建版本、命名空间包和 SSR 上下文 |
| [client.ts](client.ts) | 页面种子、异步消息获取、合并和当前客户端 |
| [namespaces.ts](namespaces.ts)、[keys.ts](keys.ts) | 命名空间及依赖闭包 |
| [negotiation.ts](negotiation.ts)、[locales.ts](locales.ts) | 请求语言与支持语言 |
| [dom.ts](dom.ts)、[messages.ts](messages.ts) | DOM 更新和站点消息访问 |

权威文本在 [public/i18n](../../public/i18n/)，每条界面文案维护全部五种语言。改命名空间需核对 [消息路由](../pages/i18n/)、种子与 SSR；不能把可见英文 fallback 当作翻译完成。浏览器加载有网络和共享状态，构建端还会计算内容身份。

验证目录结构、消息键、页面首次渲染和切换语言；命令见 [开发导航](../../docs/DEV_GUIDE.md)。
