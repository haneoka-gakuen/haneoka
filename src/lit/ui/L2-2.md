# 共享 Lit UI · L2-2

上级：[地图](../L2-2.md)。

## 职责与接口

提供站点工作区共享的集合、筛选、实体详情、媒体和弹层构件。产品规则由 [AGENTS](../../../AGENTS.md) 维护，样式见 [Styles](../../styles/L2-2.md)。

| 入口 | 责任 |
| --- | --- |
| [character-pair.ts](character-pair.ts) | 原生羁绊面板选择器，与入口拼贴共享 [面板坐标](../../lib/friendship-board.ts) |
| [browse.ts](browse.ts)、[collection-view.ts](collection-view.ts)、[facet.ts](facet.ts) | 集合视图、搜索筛选与应用栏协作 |
| [wavy-progress.ts](wavy-progress.ts) | 波形保持 SVG 几何，平移由 HTML 合成层承担；离开视口或页面隐藏时暂停 |
| [pane.ts](pane.ts)、[detail-layout.ts](detail-layout.ts)、[spec.ts](spec.ts) | 实体详情和事实排版 |
| [tile.ts](tile.ts)、[image-gallery.ts](image-gallery.ts)、[lazy-images.ts](lazy-images.ts) | 实体链接和图片呈现／加载；卡面使用完整 MP4、双视频首帧预加载与分段下载，片段切换保留上一帧 |
| [modal.ts](modal.ts)、[accordion.ts](accordion.ts)、[controls.ts](controls.ts) | 弹层、折叠、键盘和控件行为；分段控件可按需显示主快捷键和自定义原生图像；操作菜单同样接收自定义图像 |
| [sort-control.ts](sort-control.ts) | 图鉴、配队卡库与资源选择器共用的排序字段和升降序按钮 |
| [action-menu.ts](action-menu.ts)、[selection-pane.ts](selection-pane.ts) | Material 操作菜单的标签与焦点交接；选择器默认网格及可选紧凑列表、独立筛选区和状态插槽 |
| [song-summary.ts](song-summary.ts)、[difficulty-picker.ts](difficulty-picker.ts) | 正式歌曲与社区共用的详情分节、统计网格和彩色难度展示 |
| [song-actions.ts](song-actions.ts) | 正式歌曲与社区谱面的播放／谱面／Sonolus 图标、GBP 编辑器导入、谱面页下载和 2D／3D 切换 |
| [focused-value.ts](focused-value.ts) | 文本控件聚焦时保留草稿，失焦后同步模型；兼容 SSR，避免播放跟随更新覆盖输入 |
| [growth-steps.ts](growth-steps.ts) | 卡库共用的养成阶段控件；成员特训／觉醒显示阶段，留影突破显示次数，存储仍为一基阶段，未知值不预选 |
| [icon.ts](icon.ts) | Material 图标引用与原生单色图标遮罩；歌曲与竞技场共用主题色遮罩，新增 Material 图标还须生成 sprite |
| [rating.ts](rating.ts) | 游戏 D1–SS4 等级图标、最高分评级徽章与阶段星；使用固定 release 素材和共享布局 |

有些函数只返回模板，有些访问 DOM、观察器、事件与焦点，不能统一称无副作用。共享行为改动核对使用者、SSR 和水合；面向读者的消息不能混入实现说明。桌面／手机、明暗主题和键盘验证按 [开发导航](../../../docs/DEV_GUIDE.md)。
