# 交互工作区 · L2-2

上级：[地图](../L2.md)。

## 职责与生命周期

路由按需加载的 Lit 工作区负责交互与浏览器状态；部分工作区还被构建端 SSR 实例化。light DOM 与 SSR 水合契约见 [hydrate-workspace.ts](shared/hydrate-workspace.ts)。

| 任务 | 入口 |
| --- | --- |
| 资料集合和实体枢纽 | [catalog-screen.ts](catalog-screen.ts)、[catalog-table.ts](catalog-table.ts) |
| 账户、社区与管理 | [account-workspace.ts](account-workspace.ts)、[community-workspace.ts](community-workspace.ts)、[admin-workspace.ts](admin-workspace.ts) |
| 配队、Box、导入和活动 | [team-builder.ts](team-builder.ts)、`team-builder/`；计算和存储见 [配队领域](../lib/team-builder/L2-2.md) |
| 故事、Live2D、Spine、编辑器 | [story-workspace.ts](story-workspace.ts)、[live2d-workspace.ts](live2d-workspace.ts)、[spine-workspace.ts](spine-workspace.ts)、[chart-creation-workspace.ts](chart-creation-workspace.ts) |
| 公共 UI 与重型运行 | [UI](ui/L2-2.md)、[Runtime](runtime/L2-2.md) |
| 共享资料与 HTTP 工具 | [shared/catalog.ts](shared/catalog.ts)、`shared/`、`views/` |

## 枢纽与依赖边界

`catalog-screen` 协调资源类型、跨服、筛选、详情、媒体和评论；`community-workspace` 协调读取、编辑、上传和状态。先沿相应职责追踪，不为缩短文件或画图拆分它们。

配队子控制器持有父组件上下文；类型回引用与运行时循环分别判断。共享 `catalog` 工具包含 HTTP、语言、服务器选择和展示格式，`src/lib` 的若干读取器反向引用它，不能将两个目录概括成严格上下层。

连接时初始化、断开时清理事件／Worker／播放器；应用栏接管要恢复，旧异步结果要遵守已有取消和身份规则。验证入口见 [开发导航](../../docs/DEV_GUIDE.md)。
