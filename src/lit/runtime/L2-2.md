# 浏览器媒体运行适配 · L2-2

上级：[地图](../L2-2.md)。

## 职责与入口

为浏览器工作区连接媒体、画布、WebGL、声音与外部播放器，维护装载和销毁生命周期。

| 入口 | 责任 |
| --- | --- |
| [chart-simulator.ts](chart-simulator.ts)、[chart-overview-renderer.ts](chart-overview-renderer.ts) | 正式歌曲、社区与编辑器共用的 2D 概览、3D 观看、舞台、控件和下载；背景使用当前图集经验证的纯白 Sprite 近似，切源废弃旧背景；编辑器内存投影保留音频偏移、全局变速与分组速度，退出销毁查看器；社区 playback 投影带音频偏移和全局变速，游戏素材绑定 release，音频／封面保留各自服务器与 release |
| [chart-image-export.ts](chart-image-export.ts) | 共用谱面图片排版与下载，短谱面保留页头所需画布宽度 |
| [timing-chart-preview.ts](timing-chart-preview.ts) | 配队计数窗口的平面谱面片段；展开后按结果歌曲的固定 release 加载谱面与原版皮肤，按引擎规范判定流索引取得几何信息，仅框选实际提前输入；切源与断开时取消加载并释放皮肤 |
| [vega-story-stage.ts](vega-story-stage.ts) | Vega 故事播放适配 |
| [home-spot-stage.ts](home-spot-stage.ts)、[spine-stage.ts](spine-stage.ts)、[outfit-stage.ts](outfit-stage.ts) | 场景、Spine、服装舞台 |
| [audio-dock.ts](audio-dock.ts) | 声音播放与队列 |
| [native-meta-sidecar.ts](native-meta-sidecar.ts) | 按来源身份加载原生分析附加数据 |
| [viewer-resolution.ts](viewer-resolution.ts)、[viewport-fullscreen.ts](viewport-fullscreen.ts) | 渲染分辨率和视口生命周期 |
| [viewport-render-loop.ts](viewport-render-loop.ts) | 模型舞台的按需绘制；暂停、离开视口或页面隐藏时停止渲染，恢复可见时重绘 |

能力通过 [packages](../../../packages/L2.md) 与外部引擎组合；运行时、模型和授权素材是否存在分别确认。加载会请求资源并占用 GPU、音频和 DOM；离开页面、切换实体及取消时核对资源释放，避免异步旧结果覆盖新状态。

真实资源播放验收与文档／类型检查不同。验证按 [开发导航](../../../docs/DEV_GUIDE.md) 选择相应浏览器场景。

[chart-image-export.ts](chart-image-export.ts) 与图片 API 共用统计补齐和图片排版；[spine-stage.ts](spine-stage.ts) 支持按指定播放时间推进后进行同一超采样截图。
