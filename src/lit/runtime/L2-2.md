# 浏览器媒体运行适配 · L2-2

上级：[地图](../L2-2.md)。

## 职责与入口

为浏览器工作区连接媒体、画布、WebGL、声音与外部播放器，维护装载和销毁生命周期。

| 入口 | 责任 |
| --- | --- |
| [chart-simulator.ts](chart-simulator.ts)、[chart-overview-renderer.ts](chart-overview-renderer.ts) | 谱面预览、播放与概览绘制 |
| [vega-story-stage.ts](vega-story-stage.ts) | Vega 故事播放适配 |
| [home-spot-stage.ts](home-spot-stage.ts)、[spine-stage.ts](spine-stage.ts)、[outfit-stage.ts](outfit-stage.ts) | 场景、Spine、服装舞台 |
| [audio-dock.ts](audio-dock.ts)、[alpha-video.ts](alpha-video.ts) | 声音和透明视频 |
| [native-meta-sidecar.ts](native-meta-sidecar.ts) | 按来源身份加载原生分析附加数据 |
| [viewer-resolution.ts](viewer-resolution.ts)、[viewport-fullscreen.ts](viewport-fullscreen.ts) | 渲染分辨率和视口生命周期 |

能力通过 [packages](../../../packages/L2.md) 与外部引擎组合；运行时、模型和授权素材是否存在分别确认。加载会请求资源并占用 GPU、音频和 DOM；离开页面、切换实体及取消时核对资源释放，避免异步旧结果覆盖新状态。

真实资源播放验收与文档／类型检查不同。验证按 [开发导航](../../../docs/DEV_GUIDE.md) 选择相应浏览器场景。
