# Astro 路由 · L2-2

上级：[地图](../L2.md)。

## 职责与入口

路由选择 server、locale、资源类型和实体，调用 Document 组件及构建数据。`getStaticPaths` 不是单纯 URL 枚举：它可读取资料、登记构建覆盖并依赖静态输入。

| 路由 | 责任 |
| --- | --- |
| [[server]/[locale]/[kind]/index.astro](%5Bserver%5D/%5Blocale%5D/%5Bkind%5D/index.astro) | 资源集合与特殊资源分派 |
| [[server]/[locale]/[kind]/[id].astro](%5Bserver%5D/%5Blocale%5D/%5Bkind%5D/%5Bid%5D.astro) | 规范实体页 |
| [[locale]/[...slug].astro](%5Blocale%5D/%5B...slug%5D.astro) | 通用语言路由 |
| [[server]/[locale]/player-ranks/index.astro](%5Bserver%5D/%5Blocale%5D/player-ranks/index.astro)、[friendship-ranks/index.astro](%5Bserver%5D/%5Blocale%5D/friendship-ranks/index.astro) | 图鉴账号与角色羁绊经验表的独立静态页，与录音室练习一样不生成逐级实体页 |
| [[server]/[locale]/band-rating/index.astro](%5Bserver%5D/%5Blocale%5D/band-rating/index.astro) | 图鉴乐队评分门槛的独立静态表 |
| [[server]/[locale]/high-score-rating/index.astro](%5Bserver%5D/%5Blocale%5D/high-score-rating/index.astro) | 图鉴最高分评级门槛的独立静态表 |

| [i18n](i18n/)                                                                                                                          | 按内容版本／语言／命名空间输出消息                   |

正式静态页面的服务器选择见 [entity-graph.ts](../lib/entity-graph.ts) 和构建环境。新增资源类型同时核对 [resource-route.ts](../lib/resource-route.ts)、导航、页面载荷和 Worker。

`[locale]/community/charts/` 为跨服社区谱面集合；动态 UUID 实体及其 `chart/` 播放器子页共用 `[locale]/community/charts/[id].astro` 生成的 `_` 空壳，规范地址由共享静态文档查找和开发重写映射；旧 `[locale]/charts/` 与服务器前缀地址重定向，查询参数保留。实体和指定版本播放数据由带权限的社区 API 读取。

GBP／世界计划的 `/{locale}/community/{gbp|sekai}/stories/{section}/{id}/` 独立实体映射到 `provider-static` 文档；旧 `?story=`／`?card=` 地址重定向，集合与实体分别渲染。核心构建同时生成 GBP 和世界计划各分类的 `_` 独立实体壳，缺少供应方预生成详情时读取对应故事与完整目录，保持相同阅读与播放组件。

开发模式重写及生产静态文档打包见 [middleware](../middleware.ts) 与 [Server](../server/L2-2.md)。布局规则见 [Components](../components/L2-2.md)。验证按 [开发导航](../../docs/DEV_GUIDE.md)。

`[server]/[locale]/growth-data.json.ts` 提供养成详情按需读取的固定版本材料与技能资料。
图鉴与 [故事集合根路径](%5Bserver%5D/%5Blocale%5D/stories/index.astro) 提供分类入口；故事类型仍在 `stories/[mode]` 阅读。[tools](%5Blocale%5D/tools.astro) 与 [games](%5Blocale%5D/games.astro) 提供工具和游戏入口，社区根路径提供入口，推荐动态在 `/community/feeds/`，帖子和用户页的动态回退也复用 feeds 文档。首页和这些入口共用 [DestinationHub](../components/DestinationHub.astro)。

社区故事与社区谱面共用跨服层级：`[locale]/community/stories/` 集合、`[id]/` 详情及 `[id]/story/` 阅读／播放，通过 `_` 实体壳响应动态 UUID。旧服务器前缀及 `community-stories` 链接保留查询参数重定向。[故事制作器]([locale]/story-editor/create.astro) 对齐谱面制作器的 `editor/create` 入口，通过构建版本绑定同源 Altair iframe。

- [本机存档]([locale]/saves.astro)：浏览器和原生壳共用的本机存档工作区入口。
