# 前端 · L2

上级：[地图](../L1.md)。

## 职责和运行环境

Astro 静态路由与文档组件负责首屏，构建期数据和 Lit SSR 生成载荷，浏览器工作区接管交互。入口配置是 [astro.config.mjs](../astro.config.mjs)，生成与打包由 [构建工具](../scripts/build/L2-2.md) 配合。

| 区域 | 责任与继续阅读 |
| --- | --- |
| `pages/` | [路由](pages/L2-2.md)，规范地址与内部物理构建路径 |
| `components/`、`layouts/` | [文档与壳](components/L2-2.md)，AppShell 与 Base |
| `server/` | [构建数据与 SSR](server/L2-2.md)，Node 文件／网络读取 |
| `lib/` | [共享逻辑](lib/L2-2.md) → 跨服、配队与路径契约 |
| `lit/` | [交互工作区](lit/L2-2.md) → UI 与媒体运行适配 |
| `i18n/` | [国际化](i18n/L2-2.md)，服务端种子与浏览器加载 |
| `styles/` | [样式](styles/L2-2.md)，token、组件和页面规则 |
| `config/`、`data/`、`assets/`、`workers/` | 导航和页面声明、受跟踪静态输入、素材及拼图 Worker；不是下载的游戏 release |
| [middleware.ts](middleware.ts) | 开发重写、Material 首屏样式与生产静态文档打包 |

## 主要链路和边界

路由 → Document／Entity → 构建数据／Lit SSR → Base／AppShell → 页面载荷与浏览器水合。浏览器再请求 Worker、资源和播放器。`src/server` 直接复用部分 Lit；`lib` 有构建专用和浏览器文件；不能只按目录画成严格单向层。

资料资源与账户社区状态由不同系统持有。正式静态页面主要面向 jp／intl，测试服可作为数据来源；构建选择与读者可见性分别核对。缺 release、输入身份不一致、SSR 失败和浏览器网络失败有不同边界，不用空列表掩盖。

产品／界面规则见 [AGENTS](../AGENTS.md)，操作与验证见 [开发导航](../docs/DEV_GUIDE.md)。
