# 跨服目录 · L2-2

上级：[地图](../L2-2.md)。

## 职责与入口

日服与国际服按资源类别和原始 ID 合并全部同 ID 对象，各服字段、素材和 release 身份保留在来源版本中；目录可见性与静态页面生成范围分开。

| 入口 | 责任 |
| --- | --- |
| [catalog.ts](catalog.ts)、[definitions.ts](definitions.ts)、[content.ts](content.ts)、[documents.ts](documents.ts) | 目录与文档按资源类别和 ID 合并两正式服；其他来源保留所有者区分；来源字段差异仅用于版本分组与展示 |
| [load.ts](load.ts)、[static.ts](static.ts) | 注入读取器的聚合流程与构建期适配；活动详情补全不以图片或文字差异阻断 |
| [fetch.ts](fetch.ts)、[detail.ts](detail.ts)、[cache.ts](cache.ts) | 浏览器列表／详情读取及公共缓存；详情按固定 release 和对象 ID 加载，辅助 `live-tools` 文档沿同一来源身份缓存，不登记为图鉴资源 |
| [presentation.ts](presentation.ts)、[availability.ts](availability.ts) | 展示身份、来源与可用性 |
| [home.ts](home.ts)、[home-seed.ts](home-seed.ts) | 首页紧凑投影；嵌入 HTML 时省去目录已覆盖的原始文档、与目录相同的版本身份及逐字复制行字段的素材，浏览器先还原再使用 |
| [voices.ts](voices.ts) | 角色语音按原始条目和所有者关联；同一原始 Cue 的多输出采用首个声明音源；跨服同 SHA-256 录音合并五语文本，各服品牌报幕保留独立条目，媒体固定到来源 release |

消费者包括 [目录工作区](../../lit/catalog-screen.ts)、搜索与配队数据。资源服务器定义见 [resource-route.ts](../resource-route.ts)。

聚合允许部分来源失败，须沿具体调用者核对错误与完整度，不能把缺失服当作空目录或把相似记录当成同一 release。构建读取与浏览器 HTTP 的缓存和生命周期不同。验证按 [开发导航](../../../docs/DEV_GUIDE.md)。
