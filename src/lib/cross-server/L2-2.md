# 跨服目录 · L2-2

上级：[地图](../L2-2.md)。

## 职责与入口

在保留官方服身份与来源的前提下，加载、合并并呈现跨服目录；目录可见性与静态页面生成范围分开。

| 入口 | 责任 |
| --- | --- |
| [catalog.ts](catalog.ts)、[definitions.ts](definitions.ts) | 资源类别、身份、快照、合并记录 |
| [load.ts](load.ts)、[static.ts](static.ts) | 注入读取器的聚合流程与构建期适配 |
| [fetch.ts](fetch.ts)、[detail.ts](detail.ts)、[cache.ts](cache.ts) | 浏览器列表／详情读取及公共缓存 |
| [presentation.ts](presentation.ts)、[availability.ts](availability.ts) | 展示身份、来源与可用性 |

消费者包括 [目录工作区](../../lit/catalog-screen.ts)、搜索与配队数据。选择状态与测试服可见性由 [test-server-visibility.ts](../test-server-visibility.ts) 等协作；资源服务器定义见 [resource-route.ts](../resource-route.ts)。

聚合允许部分来源失败，须沿具体调用者核对错误与完整度，不能把缺失服当作空目录或把相似记录当成同一 release。构建读取与浏览器 HTTP 的缓存和生命周期不同。验证按 [开发导航](../../../docs/DEV_GUIDE.md)。
