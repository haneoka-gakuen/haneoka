## 责任与阅读路线

连接资料、Box、引擎输入、评价与资源规划。这里有浏览器状态、构建期读取、Worker 协议和纯计算，目录整体不能标为无副作用的领域库。

| 任务 | 所属入口 |
| --- | --- |
| 数据、release 身份、规则与工作区文档 | [Data](data/L2-2.md) → [data.ts](data.ts) |
| 当前主界面计算、取消、结果合并 | [Engine](engine/L2-2.md) → [client.ts](engine/client.ts) → [worker.ts](engine/worker.ts) |
| TS 搜索、证据缺口、预算、资源规划 | [Solver](solver/L2-2.md) → [optimizer.ts](optimizer.ts)、[resource-planner.ts](resource-planner.ts) |
| 当前成员／留影持久化与云同步 | [Sync](sync/L2-2.md) |
| 用户选择的存档、备份与文本导入 | [Save sources](save-sources/L2-2.md)；截图见 [媒体服务](../../../packages/community-media/L2-2.md) |
| 领域类型和既有库存格式 | [model.ts](model.ts)、[contracts.ts](contracts.ts)、[inventory.ts](inventory.ts)、[storage.ts](storage.ts) |

## 跨域契约

[界面](../../lit/team-builder.ts) 持有数据、BoxStore 和 EngineClient，并协调子控制器。`src/lit/team-builder/` 的子模块依赖父组件较大的状态表面，不因拆成文件就成为独立子系统。当前主路径是界面 → EngineClient → WASM Worker；TS solver 及旧存储路径仍存在，应按调用者区分。

数据与谱面按来源身份绑定；跨服合并、规则证据、停止原因和完成度共同影响结果含义。修改公共契约要同时核对界面、Worker API、持久格式与外部引擎。保存失败、证据缺失和搜索中止须保留各自语义。

本目录内部存在运行时回边，详见 Data；不为地图移动类型或拆分枢纽。验证按 [开发导航](../../../docs/DEV_GUIDE.md)。
