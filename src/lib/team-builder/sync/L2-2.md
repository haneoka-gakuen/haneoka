# Box 同步 · L2-2

上级：[地图](../L2-2.md)。

## 职责与流程

当前 [配队界面](../../../lit/team-builder.ts) 使用 [BoxStore](box-store.ts) 保存成员与留影状态。本地修改先落本地副本，再后台同步 [Worker Box API](../../../../worker/team-box.ts)。

| 文件 | 所有权 |
| --- | --- |
| [box-doc.ts](box-doc.ts) | Box 条目、操作、时钟、合并与格式限制；浏览器和 Worker 共享 |
| [box-store.ts](box-store.ts) | 本地存储、会话归属、网络同步与状态发布 |
| [box-view.ts](box-view.ts) | 条目到界面视图及引擎输入 |
| [legacy.ts](legacy.ts) | 旧库存转换为 Box 操作 |

Box 以服务器与账户上下文隔离；`local/syncing/pending/offline/signed-out/error` 等状态不是同一种保存结果。退出、换号、离线与冲突要核对 Store 生命周期；不能把本地写入等同云端成功。旧 [InventoryStore](../storage.ts) 和 [TeamWorkspaceStore](../data/workspace-storage.ts) 是不同文档与接口，不改名冒充 Box。

更改同步格式同时核对 Worker、数据库迁移与旧格式转换。验证入口见 [开发导航](../../../../docs/DEV_GUIDE.md)。
