# 配队数据与工作区文档 · L2-2

上级：[地图](../L2-2.md)。

## 职责与入口

将固定 release 的目录、Master、规则证据和资源阶段转成配队输入；同时维护可持久化的工作区文档。

| 入口 | 责任 |
| --- | --- |
| [../data.ts](../data.ts) | `TeamBuilderData`、基础行解析、领域适配与组装枢纽 |
| [load.ts](load.ts)、[fetch.ts](fetch.ts)、[response.ts](response.ts) | 构建期加载、浏览器请求、Worker DTO 组装 |
| [source.ts](source.ts)、[cross-server.ts](cross-server.ts) | 来源身份、跨服选取和合并 |
| [runtime-rules.ts](runtime-rules.ts)、[native-rule-evidence.ts](native-rule-evidence.ts) | 规则和原生证据；缺失与不支持不能补成确定值 |
| [resource-stage.ts](resource-stage.ts)、[reward-input.ts](reward-input.ts)、[events.ts](events.ts) | 阶段、奖励与活动输入适配 |
| [workspace-document.ts](workspace-document.ts)、[workspace-storage.ts](workspace-storage.ts)、[sync-merge.ts](sync-merge.ts) | 工作区格式、持久化和合并；与新 Box 文档分开 |

主要消费者是 [配队界面](../../../lit/team-builder.ts)、[引擎](../engine/L2-2.md) 和 [Worker 数据接口](../../../../worker/team-builder-data.ts)。构建加载经过 [静态资料源](../../static-catalog-source.ts)，不能视为纯内存读取。

## 实际边界

`data.ts` 同时定义类型和 `objectRow/nativeRow/dataRows` 等解析函数。规则、角色和资源适配又引用这些运行时函数，存在域内回边，不是严格单向分层。改变解析或组装顺序应核对双向调用，而不是只改类型。

身份至少涉及 server、release 和 source；跨服数据与当前选择不能互相替代。工作区云同步可发认证 HTTP 请求并与本地存储合并，失败和冲突按存储类状态表达。Box 的本地优先同步见 [Sync](../sync/L2-2.md)。验证见 [开发导航](../../../../docs/DEV_GUIDE.md)。
