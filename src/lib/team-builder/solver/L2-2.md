# 配队 TS 求解与证据 · L2-2

上级：[地图](../L2-2.md)。

## 职责与适用范围

维护 TS 求解、原生规则证据、谱面加载、搜索预算与恢复、实用和资源规划。当前主配队界面通过 [WASM 引擎适配](../engine/L2-2.md) 运行；本目录仍由 [optimizer](../optimizer.ts)、手动评价和资源规划等接口使用，不能将其误称为当前唯一主引擎。

| 入口 | 责任 |
| --- | --- |
| [worker.ts](worker.ts)、[../optimizer.ts](../optimizer.ts) | TS Worker 消息、优化、验证、取消和进度 |
| [evaluate.ts](evaluate.ts)、[evaluation.ts](evaluation.ts) | 队伍评价与预处理 |
| [song-loader.ts](song-loader.ts) | 根据固定来源身份读取谱面和指标 |
| [search-budget.ts](search-budget.ts)、[search-checkpoint.ts](search-checkpoint.ts)、[../search-resume.ts](../search-resume.ts) | 预算、指纹、断点与状态恢复 |
| [native-rule-profile.ts](native-rule-profile.ts)、[native-rule-evidence-producer.ts](native-rule-evidence-producer.ts) | 规则适用性与证据，连接原生普通／激奏算法 |
| [native-practical-search.ts](native-practical-search.ts)、[resource-cycle.ts](resource-cycle.ts) | 实用搜索与资源周期评估 |

## 契约与失败

输入输出见 [contracts.ts](../contracts.ts)。结果包含证据缺口、预算或取消状态；有限搜索和完整枚举不是同一保证。断点必须核对输入指纹与引擎版本，不能跨上下文复用。`native-*` 有不同规则适用域，不应把不支持的规则补成通用得分。

纯评价与可联网的谱面加载分开；Worker 有消息与内存生命周期。验证按 [开发导航](../../../../docs/DEV_GUIDE.md)，修改契约同时核对消费者和当前主引擎路线。
