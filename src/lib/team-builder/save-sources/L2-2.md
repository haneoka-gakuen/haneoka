# 本地存档来源 · L2-2

上级：[地图](../L2-2.md)。

## 职责与边界

[client.ts](client.ts) 将用户选中的文件夹、备份或归档及必要密码交给 [worker.ts](worker.ts)，处理进度、取消与终止；解析能力连接锁定的 `@haneoka/game-data-exporter`。

| 文件 | 责任 |
| --- | --- |
| [directory.ts](directory.ts) | 文件夹来源描述与读取 |
| [archive.ts](archive.ts) | 归档来源处理 |
| [ios-backup.ts](ios-backup.ts)、[backup-crypto.ts](backup-crypto.ts)、[plist.ts](plist.ts) | iOS 备份、加密和元数据解析 |
| [../box-import/client.ts](../box-import/client.ts)、[../box-import/worker.ts](../box-import/worker.ts) | 文本／文件的本地 Box 解析入口 |

这些是本地解析路径；截图识别另由 [媒体服务](../../../../packages/community-media/L2-2.md) 处理。解析完成后接受、预览、合并和持久化由导入控制器及 Box 负责，不能将“本地解析”泛化为导入全过程无网络或不保存。不要在日志或错误文案中回显密码与存档内容。

修改来源适配核对 [界面导入器](../../../lit/team-builder/importers.ts)、取消时 Worker 终止及错误类型。验证见 [开发导航](../../../../docs/DEV_GUIDE.md)。
