## 依赖与副作用

角色页按需构造当前角色的资料闭包；语音附件合并日服与国际服的固定目录，保留来源可用性、独占标记和不同音源。

`app-bar` 是 UI 基础设施，既支持 DOM 更新也支持 SSR 捕获。社区和提前读取复用 [shared/catalog.ts](../lit/shared/catalog.ts)，因此请求、语言和浏览器环境有实际交织，不是纯传输库。配队内部也有回边，分别在子地图说明。

`static-catalog-source` 可读取本地 release，也可按策略发 HTTP，并接入静态构建输入捕获。固定身份校验失败不能无条件换到当前远端 release。文件名中的 static 不等于无 I/O。

修改公共路径和文档格式同时核对 [Worker](../../worker/L2.md)、[本地预览](../../server/L2.md) 和 [构建工具](../../scripts/build/L2-2.md)。验证按 [开发导航](../../docs/DEV_GUIDE.md)。

[public-tools/team-builder.ts](public-tools/team-builder.ts) 公开现有 WASM 配队能力；[public-tools/module-worker.ts](public-tools/module-worker.ts) 通过页面本地的模块入口支持跨站调用，Blob 地址随页面存活；[public-tools/chart-image.ts](public-tools/chart-image.ts)、[public-tools/chart-meta.ts](public-tools/chart-meta.ts)、[public-tools/chart-contract.ts](public-tools/chart-contract.ts) 与网页共用原生谱面绘制、导出信息和缓存版本。[public-tools/images.ts](public-tools/images.ts) 公开全部图片导出；[public-tools/team-image.ts](public-tools/team-image.ts) 直接复用当前配队结果模板与 DOM 导出，[public-tools/team-image.css](public-tools/team-image.css)、[public-tools/images.css](public-tools/images.css)、[public-tools/fonts.css](public-tools/fonts.css) 使用网站样式。[public-tools/image-contract.ts](public-tools/image-contract.ts) 提供完整类型，[public-tools/image-routes.ts](public-tools/image-routes.ts)、[public-tools/image-validation.ts](public-tools/image-validation.ts) 为不依赖 DOM 的服务契约。另有 [public-tools/gacha.ts](public-tools/gacha.ts)、[public-tools/song-puzzle.ts](public-tools/song-puzzle.ts)、[public-tools/stamp.ts](public-tools/stamp.ts) 复用现有工具。[catalog-visuals.ts](catalog-visuals.ts) 与 [cubism-runtime.ts](cubism-runtime.ts) 支持指定公开素材根地址。

社区根页面是分类入口；`static-documents` 保留 `/community/feeds/` 为直接静态回退壳，供帖子和用户详情接管，Worker、本地预览与开发重写保持一致。
