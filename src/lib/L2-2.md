## 责任与导航

这里同时有路径规则、资料适配、领域计算和浏览器状态，也包含依赖 Node 文件系统的构建读取；按文件实际环境使用。

[官方采集契约](official-ranking.ts) 的 `finalEvent`／`finalBoards` 与 `finalArena`／`finalPopulationBands` 将保留的活动或赛季身份及本轮到期目标区分于当前目录，已采窗口复用窗口任务字段；Worker 调度并鉴权回调，Python 容器沿用新鲜版本读取这些目标。

任务能力 `arena-probes-v1` 将人数搜索中的中间页作为 `arena-probe` 回调，只确认请求与健康状态，不写排名历史；完整人数、榜首及显式窗口仍保存。`demand-progress-v1` 的完成回调报告实际尝试的需求子集，尚未执行的条目留在持久队列。

`population-priority-v1` 传递按完整人数快照新鲜度排序的乐队列表，进度可报告 `budget`／`changed` 延后原因；已尝试的进度更新时间不作为完整快照时间。

## 依赖与副作用

角色页按需构造当前角色的资料闭包；语音附件合并日服与国际服的固定目录，保留来源可用性、独占标记和不同音源。

`app-bar` 是 UI 基础设施，既支持 DOM 更新也支持 SSR 捕获。社区和提前读取复用 [shared/catalog.ts](../lit/shared/catalog.ts)，因此请求、语言和浏览器环境有实际交织，不是纯传输库。配队内部也有回边，分别在子地图说明。

`static-catalog-source` 可读取本地 release，也可按策略发 HTTP，并接入静态构建输入捕获。固定身份校验失败不能无条件换到当前远端 release。文件名中的 static 不等于无 I/O。

修改公共路径和文档格式同时核对 [Worker](../../worker/L2.md)、[本地预览](../../server/L2.md) 和 [构建工具](../../scripts/build/L2-2.md)。验证按 [开发导航](../../docs/DEV_GUIDE.md)。

[public-tools/team-builder.ts](public-tools/team-builder.ts) 公开现有 WASM 配队能力；[public-tools/module-worker.ts](public-tools/module-worker.ts) 通过页面本地的模块入口支持跨站调用，Blob 地址随页面存活；[public-tools/chart-image.ts](public-tools/chart-image.ts)、[public-tools/chart-meta.ts](public-tools/chart-meta.ts)、[public-tools/chart-contract.ts](public-tools/chart-contract.ts) 与网页共用原生谱面绘制、导出信息和缓存版本。[public-tools/images.ts](public-tools/images.ts) 公开全部图片导出；[public-tools/team-image.ts](public-tools/team-image.ts) 直接复用当前配队结果模板与 DOM 导出，[public-tools/team-image.css](public-tools/team-image.css)、[public-tools/images.css](public-tools/images.css)、[public-tools/fonts.css](public-tools/fonts.css) 使用网站样式。[public-tools/image-contract.ts](public-tools/image-contract.ts) 提供完整类型，[public-tools/image-routes.ts](public-tools/image-routes.ts)、[public-tools/image-validation.ts](public-tools/image-validation.ts) 为不依赖 DOM 的服务契约。另有 [public-tools/gacha.ts](public-tools/gacha.ts)、[public-tools/song-puzzle.ts](public-tools/song-puzzle.ts)、[public-tools/stamp.ts](public-tools/stamp.ts) 复用现有工具。[catalog-visuals.ts](catalog-visuals.ts) 支持指定公开素材根地址；[cubism-runtime.ts](cubism-runtime.ts) 惰性导入与制作器共用的 SDK 适配器，Core 依锁定清单优先使用同版原生 WASM，并保留经典脚本来源。

社区根页面是分类入口；`static-documents` 保留 `/community/feeds/` 为直接静态回退壳，供帖子和用户详情接管，Worker、本地预览与开发重写保持一致。

官方采集的 `attempt` 可携带榜单窗口身份及保留意图；能力协商后的回执区分允许读取、复用原观测与延期，150 秒窗口由区域 DO 跨任务持有。
