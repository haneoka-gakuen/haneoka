# 构建数据与 Lit SSR · L2-2

## 职责

为 Astro 构建准备 release、供应方、页面数据和 Lit SSR。这里使用 Node 环境；仓库根 `server/` 是独立的本地 HTTP 预览服务，线上动态 API 属于 Worker。

## 状态、失败和跨域关系

数据读取可能访问文件和 HTTP；供应方快照、HTTP 缓存、静态输入及生成文档是不同状态。固定 release 或重放输入不一致应按实现中止，不能拼接新的 current 数据。SSR 直接复用 [Lit 工作区](../lit/L2-2.md)，是实际耦合，不能画成完全隔离的模板层。

Sonolus 公开目录 GET 在网络、限流和服务端临时错误下最多尝试三次；目录校验仍是冻结前提，捕获入口保留失败生产者名称。

静态文档由 [middleware](../middleware.ts) 与构建收尾工具共同写出，Worker 再读取同一分片契约。修改身份／清单同步检查 [流水线生产者](../../scripts/build/L2-2.md)、[Worker](../../worker/L2.md) 和 [本地预览](../../server/L2.md)。验证按 [开发导航](../../docs/DEV_GUIDE.md)。
