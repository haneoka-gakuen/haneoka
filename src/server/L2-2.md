# 构建数据与 Lit SSR · L2-2

上级：[地图](../L2.md)。

## 职责

为 Astro 构建准备 release、供应方、页面数据和 Lit SSR。这里使用 Node 环境；仓库根 `server/` 是独立的本地 HTTP 预览服务，线上动态 API 属于 Worker。

| 入口 | 所有权 |
| --- | --- |
| [release-catalog.ts](release-catalog.ts) | 验证本地指针、清单和分片，提供 `ReleaseCatalog` 与带边界的错误 |
| [catalog-collection.ts](catalog-collection.ts)、[tool-page-data.ts](tool-page-data.ts) | 目录和工具页面的紧凑数据载荷 |
| [render-workspace.ts](render-workspace.ts)、[render-catalog.ts](render-catalog.ts)、[render-tools.ts](render-tools.ts) | 安装 DOM shim、国际化上下文、应用栏捕获及工作区静态渲染 |
| [provider-source-cache.ts](provider-source-cache.ts)、[provider-http-cache.ts](provider-http-cache.ts)、[provider-projector.ts](provider-projector.ts) | 供应方 HTTP 捕获、缓存及投影；与 Worker 共享读取接口 |
| [static-input-store.ts](static-input-store.ts)、[prepare-static-inputs.ts](prepare-static-inputs.ts) | 捕获／重放构建输入并检查一致性 |
| [static-documents.ts](static-documents.ts)、[static-build.ts](static-build.ts) | 文档内容、分片索引、页面构建范围和产物登记 |

## 状态、失败和跨域关系

数据读取可能访问文件和 HTTP；供应方快照、HTTP 缓存、静态输入及生成文档是不同状态。固定 release 或重放输入不一致应按实现中止，不能拼接新的 current 数据。SSR 直接复用 [Lit 工作区](../lit/L2-2.md)，是实际耦合，不能画成完全隔离的模板层。

静态文档由 [middleware](../middleware.ts) 与构建收尾工具共同写出，Worker 再读取同一分片契约。修改身份／清单同步检查 [流水线生产者](../../scripts/build/L2-2.md)、[Worker](../../worker/L2.md) 和 [本地预览](../../server/L2.md)。验证按 [开发导航](../../docs/DEV_GUIDE.md)。
