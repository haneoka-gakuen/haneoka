# 样式系统 · L2-2

上级：[地图](../L2.md)。

## 职责与所有权

以 Material 3 Expressive token 和共享样式建立页面视觉；具体约束只在 [AGENTS](../../AGENTS.md) 维护。

| 区域 | 责任 |
| --- | --- |
| [destination-hub.css](destination-hub.css) | 首页与五类入口共用的完整拼贴、相关操作块和响应式布局；统一中性灰底；素材按原始比例展开叠放，编成和羁绊保留游戏结构 |
| [base/tokens.css](base/tokens.css)、[base/typography.css](base/typography.css) | 语义 token 和字体排版 |
| [system/layout.css](system/layout.css) | 跨页面布局工具 |
| [index.css](index.css) | 样式组合与跨层工具规则；App／视口全屏解除内容区裁剪并隐藏壳栏 |
| [game-glyph.css](components/game-glyph.css) | 歌曲与竞技场共用的原生单色图标遮罩，随 Material 主题着色 |
| [components](components/) | 控件、列表、表格、弹层等共享构件 |
| [gacha-prize-card.css](components/gacha-prize-card.css) | 抽卡模拟器和历史记录共用的卡牌 grid、属性及稀有度样式，由共享卡牌模块加载 |
| [patterns/song.css](patterns/song.css)、[difficulty-picker.css](difficulty-picker.css) | 正式歌曲与社区共用的详情分节、统计与难度块 |
| [patterns/chart.css](patterns/chart.css) | 正式歌曲、社区与编辑器预览共用的谱面页、概览和播放布局 |
| [patterns](patterns/) | 集合、浏览和实体详情模式；`collection.css` 在图片失败时保留卡片角标可读，图片实际请求期间显示加载动画；头像堆叠支持角色链接和可调重叠，头像保持正圆 |
| [patterns/detail.css](patterns/detail.css) | 详情事实与奖励分组；短数值使用紧凑网格，奖励行使用可缩至单列的宽分组 |
| [shell](shell/) | 应用壳与导航 |
| 本层页面 CSS | 独有页面视觉，按页面根类和 layer 限定作用域 |
| [arena.css](arena.css) | 竞技场当前行与紧凑规则标识；复用页面、surface、表格和折叠组件 |

CSS 的实际加载由 Astro 文档和 Lit 导入决定；相邻文件不保证同时加载。light DOM 会共享规则，需检查选择器范围。不要复制其他页面私有样式或以字面颜色取代系统 token。

验证受影响页面在桌面／手机、明暗主题、长文本、加载和错误状态的稳定布局；详见 [开发导航](../../docs/DEV_GUIDE.md)。
