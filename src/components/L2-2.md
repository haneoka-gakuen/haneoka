# Astro 文档与页面壳 · L2-2

上级：[地图](../L2.md)。

## 职责与结构

[AppShell.astro](AppShell.astro) 拥有应用栏、全局导航和页面壳；`contained` 工具表面关闭外层滚动和预留滚动槽，内部面板各自滚动；导航分组与子分支可折叠，保留链接入口并保存展开选择；[Base.astro](../layouts/Base.astro) 是文档基础布局。Document 组件连接页面数据、SSR、脚本和样式，`entities/`、`pages/` 组合具体页面。

| 入口 | 责任 |
| --- | --- |
| [DestinationHub.astro](DestinationHub.astro)、[HubDocument.astro](HubDocument.astro)、[HubArtwork.astro](HubArtwork.astro) | 图鉴、故事、工具、游戏和社区入口；首页概览下方共用完整入口拼贴；按图片比例和功能主次分配大小，相关操作组合在同一块内；素材由 [hub data](../server/destination-hub-data.ts) 投影，内容编排来自 [destination-hubs](../config/destination-hubs.ts) |
| [RouteDocument.astro](RouteDocument.astro) | 依据路由定义组合页面 |
| [CommunityDocument.astro](CommunityDocument.astro)、[StoryDocument.astro](StoryDocument.astro) | 社区与故事文档 |
| [CommunityChartsDocument.astro](CommunityChartsDocument.astro)、[entities/CommunityChartEntityPage.astro](entities/CommunityChartEntityPage.astro) | 社区谱面集合、动态实体和播放器子页共用壳；用户谱面不进入静态资料载荷 |
| [entities/CatalogEntityPage.astro](entities/CatalogEntityPage.astro) | 资料实体页面组合；最终 payload 由 [共享 projector](../server/catalog-page-projector.ts) 生成 |
| [pages/TeamBuilderPage.astro](pages/TeamBuilderPage.astro) | 配队页面数据、样式和工作区挂载 |
| [LevelExperienceDocument.astro](LevelExperienceDocument.astro) | 账号与统一角色羁绊等级经验表，读取 progression 并复用共享数字表格；显示单级所需经验和累计经验 |
| [BandRatingDocument.astro](BandRatingDocument.astro) | 乐队等级的综合与单乐队评分门槛静态表，读取 progression，使用游戏 D1–SS4 图标并复用共享数字表格 |
| [HighScoreRatingDocument.astro](HighScoreRatingDocument.astro) | 最高分评级的乐队与综合门槛静态表，使用[共用构建读取器](../server/high-score-rating-page-data.ts)固定数据与 UI 图集；显示游戏段位徽章及五颗阶段星，按段位和阶段排序 |

数据准备属于 [Server](../server/L2-2.md)，交互属于 [Lit](../lit/L2-2.md)，界面与布局约束由 [AGENTS](../../AGENTS.md) 维护。脚本导入可能注册元素并加载运行时，不能只按 Astro 模板文本判断副作用。

Base 在页面加载后的空闲时段以低优先级加载 Google Analytics；连接失败或三秒超时静默放弃，成功后初始化一次，页面浏览沿用 Google 的历史记录增强型衡量。
Base 同时安装共用全屏生命周期：移动 App 通过原生接口请求横屏，触屏浏览器请求方向锁，桌面保留方向；退出、切页和全屏节点移除时恢复。
Base 内嵌生日角色的 ID、配色、日期和头像，供自动日期主题与导航品牌共用；切页和主题变化同步恢复品牌图标。

应用栏的滚动表面只跟随主内容容器跨越顶部边界；筛选面板、表格和其他内层滚动不改变应用栏颜色。

改壳要检查 SSR 首屏、应用栏捕获／接管、导航和水合；可见变化按 [开发导航](../../docs/DEV_GUIDE.md) 做桌面、手机及明暗主题验收。
