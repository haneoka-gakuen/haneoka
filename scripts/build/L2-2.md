# 资源与前端构建 · L2-2

上级：[地图](../L2.md)。

## 两条构建路径

Python 阶段从 Master／提取结果构造资源 release；Node／TS 工具准备前端、供应方快照和部署静态文档。共处一个目录不表示它们有相同环境或副作用。

| 入口 | 所有权 |
| --- | --- |
| [api.py](api.py)、[team_builder_data.py](team_builder_data.py) | 规范目录和配队资料投影 |
| [catalog_storage.py](catalog_storage.py) | 不可变目录、视图、关系和来源索引的存储编译 |
| [release.py](release.py) | 清单与身份、资源组装及本地 current 选择 |
| [live2d.py](live2d.py)、[spine.py](spine.py)、[home_spots.py](home_spots.py) | 模型、场景和预览资源 |
| [team-builder-engine.mjs](team-builder-engine.mjs) | 外部 Rust 引擎编译为浏览器 WASM |
| [provider-static.mjs](provider-static.mjs)、[provider-static.ts](provider-static.ts) | 供应方快照与静态输出 |
| [static-build-inputs.mjs](static-build-inputs.mjs)、[static-build-shards.mjs](static-build-shards.mjs) | 构建输入身份、封装、分片归属和完整覆盖校验 |
| [finalize-frontend.mjs](finalize-frontend.mjs)、[publish-static-documents.mjs](publish-static-documents.mjs) | 前端收尾与静态文档上传；后者有远端写入 |
| [prepare-fonts.mjs](prepare-fonts.mjs)、[icon_sprite.py](icon_sprite.py) | 字体与图标准备；其余 `*-fonts`、日历工具服务特定页面 |

## 跨域与失败

资源格式源头见 [Core](../core/L2-2.md)，验证与远端指针切换分别归 [Verify](../verify/L2-2.md)、[Publish](../publish/L2-2.md)。本地组装可写当前选择，不等同已发布。

前端构建会写生成目录、执行外部编译并可能读取供应方 HTTP、资源与字体，不能视为无网络的文档检查。页面分片、固定输入和 publication 收据不一致应中止，缺资源与授权 runtime 分别记录。消费者为 [src/server](../../src/server/L2-2.md)、[Worker](../../worker/L2.md) 和 [CI](../../.github/L2.md)。验证见 [开发导航](../../docs/DEV_GUIDE.md)。
