# 数据库操作工具 · L2-2

上级：[地图](../L2.md)。

## 职责与边界

| 入口 | 责任 |
| --- | --- |
| [snapshot_schema.ts](snapshot_schema.ts)、[schema.ts](schema.ts) | 无行数据结构快照与结构辅助 |
| [create_plan.ts](create_plan.ts)、[apply_plan.ts](apply_plan.ts) | 忽略的本地变更计划及本地应用 |
| [wrangler.ts](wrangler.ts) | Wrangler 调用适配 |
| [grant_admin.ts](grant_admin.ts) | 管理员授权操作；不是普通只读检查 |
| [prepare_event_ranking_backfill.ts](prepare_event_ranking_backfill.ts) | 活动历史回填准备 |

结构与迁移所有权见 [Worker database](../../worker/database/L2-2.md)，命令由 [数据库 README](../../worker/database/README.md) 维护。快照、本地计划、远端快照、授予管理员权限及生产迁移的副作用不同；不能仅因脚本在本地执行就认定不会访问远端。

更改数据库工具核对参数、目标选择和生成文件路径。验证见 [开发导航](../../docs/DEV_GUIDE.md)，不要为验证文档执行真实数据库写入。
