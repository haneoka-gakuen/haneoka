# 资源与导航验证 · L2-2

上级：[地图](../L2.md)。

## 职责与入口

| 入口 | 检查范围 |
| --- | --- |
| [source.py](source.py) | source 身份、清单、大小／摘要和 Master 来源 |
| [release.py](release.py) | release 清单、资源引用与目录存储一致性；可写验证报告 |
| [remote.py](remote.py) | 已发布远端对象检查，需要网络与对应访问条件 |
| [selected_native.py](selected_native.py)、[selected_addressables_settings.py](selected_addressables_settings.py) | 被选择的原生／Addressables 输入审查 |
| [geb.py](geb.py) | 本地地图、链接、层级、范围与核心 L3；标准库、无网络 |

资源验证由 [pipeline.py](../pipeline.py) 调度。检查级别与 CLI 选项决定是否读取所有字节、联网或写报告，不能将 fast inventory 视为完整摘要验证。失败要保留真实边界，不能为通过而补造缺失文件。

GEB 检查只证明导航结构和可机械检查的头信息；人工仍须核对职责、副作用与实现一致性。`--base` 可用于本轮纯文档／注释变更的正文保护，日常业务修改不启用这一限制。操作与命令见 [开发导航](../../docs/DEV_GUIDE.md)。
