# 资源发布与专项投影 · L2-2

上级：[地图](../L2.md)。

## 职责

[r2.py](r2.py) 负责 source／release 的 R2 读写、恢复、保留和 GC；其余文件将公告、故事身份、卡牌识别、商店、曲目分析等专项投影发布到既有 release 体系。

| 入口 | 责任 |
| --- | --- |
| [catalog_pages.py](catalog_pages.py) | 从完成的公开 release 按 CAS 摘要取目录输入；页面对象条件创建，不切换资源 current |
| [reward_catalog.py](reward_catalog.py) | 从固定 release 补聊天装扮目录与奖励链接，复用主页剧情；审阅候选身份后条件发布 |
| [r2.py](r2.py) | 不可变对象上传、校验、current 指针与清理；保留 App 当前完整离线版本所引用的 release |
| [app_downloads.py](app_downloads.py)、[download_store.py](download_store.py) | 校验 GitHub 正式安装包、改写分发清单并上传独立下载桶，全部成功后切换最新指针；存储适配支持 S3 与显式选用的本机 Wrangler 身份 |
| [story_offline.py](story_offline.py) | 从完整正式服 release 编译 App 剧情依赖，按章节发布内容清单和对象允许索引；媒体复用该 release 的 CAS，清单跟随 release 保留与回收 |
| [stages.py](stages.py)、[runtime_projection.py](runtime_projection.py) | 阶段／运行投影协作 |
| [announcements.py](announcements.py)、[home_spot_repair.py](home_spot_repair.py)、[missions.py](missions.py) | 公告、场景修复、任务投影 |
| [song_reference.py](song_reference.py)、[sonolus.py](sonolus.py) | 歌曲参考与 Sonolus 产物 |
| [spine_preview_repair.py](spine_preview_repair.py) | 固定正式图谱，仅重渲真实 Spine 预览并条件发布；保留原始 Unity／CRI 与生产者条目 |

发布先验证并上传对象／清单，再切换指针；增量复用要核对基线清单，不把部分完成发布成完整 release。远端验证、恢复、发布、prune 和 GC 是不同操作，其中清理会删除远端对象，必须按实际授权与 dry-run 审查执行。

命令与配置由 [Scripts README](../README.md) 维护；格式见 [Core](../core/L2-2.md)，校验见 [Verify](../verify/L2-2.md)，自动触发见 [CI](../../.github/L2.md)。验证入口见 [开发导航](../../docs/DEV_GUIDE.md)。
