# 资源提取 · L2-2

上级：[地图](../L2.md)。

## 职责与入口

从已选 source 解出 Master、Unity 和 CRI；保留来源身份和处理报告，不决定远端发布。

| 入口 | 责任 |
| --- | --- |
| [master.py](master.py) | Master 解码与清单验证 |
| [unity.py](unity.py) | Unity shard 提取和资源报告 |
| [unity_reuse.py](unity_reuse.py) | 增量计划与已有提取结果复用 |
| [cri.py](cri.py) | CRI 音视频提取和转换 |

调度见 [pipeline.py](../pipeline.py)，合并与领域输出见 [Build](../build/L2-2.md)。本地输出、外部解码进程、线程或分片由具体实现管理。复用必须核对 source、处理器身份与摘要；失败不得伪造完整提取。

完整工具链、已授权输入和 Python 依赖是执行前提。只解析源码不证明真实素材提取成功；验证见 [开发导航](../../docs/DEV_GUIDE.md)。
