# 流水线共享契约 · L2-2

上级：[地图](../L2.md)。

## 职责与权威来源

| 入口 | 责任 |
| --- | --- |
| [contracts.py](contracts.py) | source／build／release 等版本化格式和身份描述 |
| [storage.py](storage.py) | 存储布局与分片算法 |
| [manifests.py](manifests.py)、[hashes.py](hashes.py) | 稳定 JSON、原子写入和摘要 |
| [paths.py](paths.py) | source／build／release 路径与路径约束 |
| [config.py](config.py)、[private_config.py](private_config.py)、[server_policy.py](server_policy.py) | 公共配置、私有配置和服务器策略 |
| [fingerprints.py](fingerprints.py)、[delta.py](delta.py) | 生产者指纹与增量复用依据 |
| [process.py](process.py)、[unity_objects.py](unity_objects.py) | 外部进程／文件操作与 Unity 辅助 |

共享代码仍可能读写文件、调用外部进程或读取环境；不能因 core 命名标为纯函数。流水线各阶段共享契约但没有一个覆盖全部阶段的文件事务。

身份／清单／分片变更同步检查 [构建生产者](../build/L2-2.md)、[验证](../verify/L2-2.md)、[发布](../publish/L2-2.md)、[构建端读取](../../src/server/L2-2.md)、[Worker](../../worker/L2.md) 与 [本地预览](../../server/L2.md)。跨语言重复校验有独立运行环境依据，不在文档中承诺自动同步。验证见 [开发导航](../../docs/DEV_GUIDE.md)。
