# Garupa Master 工具 · L2-2

上级：[地图](../L2.md)。

## 职责与导航

独立处理 Garupa Master 的封装、协议、投影与存储，操作以 [README](README.md) 为准，不混作 Our Notes 主流水线的普通阶段。

| 入口 | 责任 |
| --- | --- |
| [__main__.py](__main__.py) | 命令入口 |
| [wire.py](wire.py)、[schema.py](schema.py) | 协议与结构 |
| [package.py](package.py)、[archive.py](archive.py)、[projection.py](projection.py) | 包、归档与投影 |
| [client.py](client.py)、[r2.py](r2.py)、[local_r2.py](local_r2.py) | 获取与远端／本地存储适配 |
| [tests](tests/) | 包、投影、R2 与 wire 的 unittest |

真实客户端和 R2 操作可能联网和写入；测试使用的替身不证明生产访问成功。CI 当前选择这里的 Python 测试，不能据此声称全仓测试已覆盖。验证见 [开发导航](../../docs/DEV_GUIDE.md)。
