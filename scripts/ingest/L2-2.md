# 资源摄取 · L2-2

上级：[地图](../L2.md)。

## 职责与流程

根据服务器配置、用户提供的包或已选来源建立可校验的 source 快照。入口由 [pipeline.py](../pipeline.py) 调度，操作见 [Scripts README](../README.md)。

| 文件 | 责任 |
| --- | --- |
| [apks.py](apks.py) | APK／APKS 等包摄取与快照 |
| [bootstrap.py](bootstrap.py)、[version_api.py](version_api.py) | 实时服务版本及配置解析 |
| [catalog.py](catalog.py)、[addressables.py](addressables.py) | Addressables 目录和来源身份 |
| [unity.py](unity.py)、[reuse.py](reuse.py)、[bundle_crypto.py](bundle_crypto.py) | Unity 下载、已知资源复用及包解码 |
| [master.py](master.py) | Master 来源下载和校验 |

网络、磁盘和凭据只按所选操作使用；摄取失败应保留已发布 release。来源探测、目录版本与 Master 版本不能相互代替。大小／摘要错误和不可用版本按有界策略失败或恢复，不把旧包覆盖当前身份。

离线重建不应进入摄取阶段，规则由 CLI 与验证共同执行。改变 source 格式核对 [Core](../core/L2-2.md)、[Extract](../extract/L2-2.md) 和 [Verify](../verify/L2-2.md)。验证见 [开发导航](../../docs/DEV_GUIDE.md)。
