## 数据流与失败

来源 → 校验快照 → 提取／复用 → 领域目录与媒体 → release 组装与验证 → 可选发布。source、build、release 和 current 指针是不同身份与生命周期；增量路径必须保持清单与生产者指纹一致。失败不得将部分产物标为发布完成。

文件、网络、外部进程和远端写入随命令不同，不能将全部脚本视作测试。`run --offline --source` 与显式 restore／publish 分开，离线缺输入不自动联网补齐。下载、真实数据、R2、数据库和部署需处于任务授权内。

验证命令见 [开发导航](../docs/DEV_GUIDE.md)，生产操作见相应 README 和工作流；不在地图复制凭据、实时状态或完整参数表。
