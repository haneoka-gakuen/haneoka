# Support

| Request | Channel |
| --- | --- |
| Setup or usage question | [Q&A Discussions](https://github.com/haneoka-gakuen/haneoka/discussions/categories/q-a) |
| Product idea | [Ideas Discussions](https://github.com/haneoka-gakuen/haneoka/discussions/categories/ideas) |
| Reproducible bug | [Bug report](https://github.com/haneoka-gakuen/haneoka/issues/new?template=bug_report.yml) |
| Catalog or resource problem | [Resource report](https://github.com/haneoka-gakuen/haneoka/issues/new?template=resource_report.yml) |
| Documentation problem | [Documentation correction](https://github.com/haneoka-gakuen/haneoka/issues/new?template=documentation.yml) |
| Feature request | [Feature proposal](https://github.com/haneoka-gakuen/haneoka/issues/new?template=feature_request.yml) |
| Security vulnerability | [Private reporting](SECURITY.md) |

Bug reports should include reproduction steps, expected and actual behavior,
the affected URL or command, environment details, and screenshots or logs with
secrets removed.

The project does not provide game packages, credentials, private resource
access, access-control bypass instructions, or legal advice.
