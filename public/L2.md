# 静态资产与消息目录 · L2

上级：[地图](../L1.md)。

## 职责与所有权

| 区域 | 责任 |
| --- | --- |
| [i18n](i18n/) | 五语界面文本，加载和种子规则见 [国际化](../src/i18n/L2-2.md) |
| [images](images/)、图标与 manifest | 可再分发的站点素材与应用标识 |
| [sw.js](sw.js) | Service Worker 缓存／请求生命周期，修改须核对客户端更新行为 |
| [basis](basis/)、[tools](tools/)、[licenses](licenses/) | 浏览器运行辅助、工具静态文件与许可 |

前端准备把所需内容组合到忽略的 `.generated-public/`，Astro 配置以该生成目录作为 publicDir，不能假设编辑 public 就已经形成部署产物。资源 release、游戏包、运行时及账号数据不属于本目录。

许可边界见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)。更新文案维护全部五语；新增生成资产核对 [构建工具](../scripts/build/L2-2.md)。验证见 [开发导航](../docs/DEV_GUIDE.md)。
