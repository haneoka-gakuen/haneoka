# 本地 Worker 与网关配置 · L2

上级：[地图](../L1.md)。

## 职责与边界

[local-gateway/worker.ts](local-gateway/worker.ts) 包装 Bestdori 代理与 CORS；[local-gateway/wrangler.jsonc](local-gateway/wrangler.jsonc) 和 [local-worker/wrangler.jsonc](local-worker/wrangler.jsonc) 提供本地开发配置。

[本地容器兼容入口](local-containers/entrypoint.sh) 保留较新 Linux 内核下的 Docker bridge 控制通信；[Docker 适配](local-containers/docker.sh) 为 Wrangler 解析该本地镜像，其余操作交给真实引擎；[Dockerfile](local-containers/Dockerfile) 固定代理镜像，启用及真实上传验证见其 [README](local-containers/README.md)。该修正只作用于开发侧车网络命名空间。

代理可以联网，Wrangler 本地运行会创建本地状态并监听端口。本地配置没有覆盖生产全部 D1、R2、队列、容器与服务能力，不能视为与根 [wrangler.jsonc](../wrangler.jsonc) 等价。

公开接口实现由 [Worker](../worker/L2.md) 持有；预览见 [Server](../server/L2.md)。修改代理需核对路径白名单、CORS、转发头与本地目标，验证入口见 [开发导航](../docs/DEV_GUIDE.md)。
