# 谱面编辑包 · L2-2

上级：[地图](../L2.md)。

## 职责与接口

提供独立的谱面模型、格式转换、编辑和视图能力；导入与新建工程使用相同字段及验证，公开导出以 [package.json](package.json) 为准；用法和许可见 [README](README.md)。

| 入口 | 责任 |
| --- | --- |
| [src/formats/mmws.ts](src/formats/mmws.ts) | MMWS／CCMMWS／UCMMWS 二进制导入与 CCMMWS v6 导出；转换可对应的节点、公共速度时间线、图层、路标、技能及 FEVER，拒绝无法对应的游戏扩展 |
| [src/formats/sus-export.ts](src/formats/sus-export.ts) | SUS 写入、共用按小节定位和可表示性诊断；保留整数 Tick，拒绝小节内拍号变化、小数 SUS 几何及左右不同缓动；技能与 FEVER 双向转换 |
| [src/formats/usc.ts](src/formats/usc.ts)、[sus.ts](src/formats/sus.ts) | SEKAI 输入映射到规范 Our Notes 工程；兼容旧 USC 及新版 guide／judgeType／同一变速时间线的分组，复合缓动拆成隐藏控制点；不能表达的独立分组变速拒绝导入；SUS 小节长度只识别数字小节频道 |
| [src/index.ts](src/index.ts) | 包接口 |
| [src/formats/ss.ts](src/formats/ss.ts) | 默认仅编码规范工程字段，来源记录及格式版本不参与播放或普通导出；`preserveSource` 为显式归档选项 |
| [src/model.ts](src/model.ts)、[src/formats](src/formats/) | 内部模型与外部格式；可选 `waypoints` 保存具名整数 Tick 创作路标，与游戏事件分开校验和排序；可编辑根对象顺序，坐标基准可按比例变换而保持舞台几何 |
| [src/creation/actions.ts](src/creation/actions.ts)、[src/creation/collections.ts](src/creation/collections.ts) | 单个中间节点插入，全部控制点可切换普通／隐藏／自动模式，保留端点、同 Tick 节点和连接器分组／图层归属；图案剪贴板支持镜像与横向位移粘贴，可复制两点以上所选滑条片段并解析新自动端点；整数 Tick 压缩保留同时性，跨越未选节点时拒绝整个操作；所选变速点间按当前细分做线性插值 |
| [src/creation/connectors.ts](src/creation/connectors.ts) | 同类型滑条端点合并、中间节点拆分；保留格式记录与分组／图层，速度不兼容时拒绝合并；选定三点以上路径可向后重复至原尾端，沿曲线按网格生成 Trace 可保留或替换滑条 |
| [src/creation/authoring.ts](src/creation/authoring.ts) | 新音符与宽度编辑；边缘拖动对选区应用共同宽度差，固定各自另一侧边缘，按共同边界限位并从原始形状解析自动节点 |
| [src/history.ts](src/history.ts)、[src/validation.ts](src/validation.ts) | 编辑历史与校验 |
| [src/creation/span.ts](src/creation/span.ts)、[src/creation/selection.ts](src/creation/selection.ts) | 编辑边界与成组位移：单音符须与谱面重叠，滑条控制点保留完整创作几何；新建、导入、复制共用规则，宿主原生编译统一验证可判定区域 |
| [src/timing.ts](src/timing.ts)、[src/viewport.ts](src/viewport.ts)、[src/waveform.ts](src/waveform.ts) | 时间、拍数／分数到整数 Tick 的解析、视口与波形；吸附／微调／节点生成可指定每单位拍数，站点按全音符显示细分 |

站点 [创作工作区](../../src/lit/chart-creation-workspace.ts) 负责用户流程、资源加载与存储，不能把宿主能力归给包。格式、历史及时间变更同时核对导入导出与撤销；浏览器／音频相关文件按实际环境执行。验证命令见 [开发导航](../../docs/DEV_GUIDE.md)。
