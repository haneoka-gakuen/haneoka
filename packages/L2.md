## 输入、状态与验证

纯类型／转换、按调用联网的 loader、创建 DOM／渲染器的 mount 和启动服务的模块有不同副作用。不能把所有包称为纯库，也不能把源代码或 README 的发行准备状态当作已发布注册表版本。

修改公开接口核对包构建、类型、宿主调用与 exports；适配外部引擎时检查锁定提交和兼容性。重型播放器须管理取消与 dispose；服务状态和业务数据不放在包内。验证入口见 [开发导航](../docs/DEV_GUIDE.md)，用法和许可继续进入各包 README。

[api-client/src/game.ts](api-client/src/game.ts)、[api-client/src/game-types.ts](api-client/src/game-types.ts) 提供完整实时游戏客户端及响应类型；[tools-service/server.mjs](tools-service/server.mjs) 是本地计算与原生图片服务入口。

Bestdori／Sekai 场景解析及资源协议由独立 Altair Bestdori 适配器统一提供；站点包保留谱面与缓存接口。
