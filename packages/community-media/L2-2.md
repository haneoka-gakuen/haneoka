# 私有媒体与截图识别服务 · L2-2

上级：[地图](../L2.md)。

## 职责与执行边界

| 入口 | 责任 |
| --- | --- |
| [worker.ts](worker.ts) | 截图识别 HTTP 适配、认证权限、限流、参考资源和容器调用 |
| [client.ts](client.ts) | 客户端识别协议 |
| [server.mjs](server.mjs) | 容器 HTTP 服务、上传、任务队列、转码进程、临时文件与清理 |
| [recognition.mjs](recognition.mjs)、[recognition](recognition/) | 图像识别服务和 Python 处理 |
| [Dockerfile](Dockerfile) | 容器环境和工具 |

这是站点私有集成服务。`worker.ts` 直接依赖 [Worker auth](../../worker/auth.ts) 与 [access](../../worker/access.ts)，以及 D1 和容器绑定，不是与站点无关的通用 npm 库。媒体任务调度和持久状态在 [worker/community-media.ts](../../worker/community-media.ts)，实际处理在容器。

请求涉及私人截图、参考资源、服务认证、CPU／内存、子进程与临时输出。上传、识别／转码、审核、可发布是不同阶段；超时、重试和租约由对应实现持有。验证需本地容器与绑定，纯地图检查不启动媒体服务；见 [开发导航](../../docs/DEV_GUIDE.md)。
