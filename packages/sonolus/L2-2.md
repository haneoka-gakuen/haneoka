# Sonolus 站点适配 · L2-2

上级：[地图](../L2.md)。

## 职责与分工

[README](README.md) 维护包边界。[src/index.ts](src/index.ts) 对外组合站点适配；本包提供 release-backed 目录、level 模板与运行谱面数据，`scripts/` 组装皮肤、音效、粒子和 Worker 资源，素材与适配代码保留各自许可。

转换来自 `@haneoka/cassiopeia-plugin-sonolus`，四种引擎目标来自外部 `@haneoka/sonolus-our-notes`。通用目录／检索／服务抽象在 [sonolus-core](../sonolus-core/README.md)，HTTP 与存储在 [Worker](../../worker/L2.md) 和 [本地预览](../../server/L2.md)。

Play／Watch 在预处理阶段缓存长键时间，以连接段自身的链表排序并合并持续音效区间；重播继续按流读取下一段，保留双层长键音效。

[独立 Sonolus 仓库](../../.dependencies/sonolus-our-notes) 随源码分发皮肤、粒子、音效和舞台背景，并提供基于 Sonolus Express 的启动入口。[scripts/build-worker-assets.ts](scripts/build-worker-assets.ts) 读取同一份资源和四个引擎产物，为 Worker 生成全局包。正式谱面目录随各服发布版本更新。素材需要重制时，由 [scripts/build-original-assets.ts](scripts/build-original-assets.ts) 和 [scripts/build-background.ts](scripts/build-background.ts) 准备候选，审核后随独立仓库更新。验证见 [开发导航](../../docs/DEV_GUIDE.md)。

[scripts/build-original-assets.ts](scripts/build-original-assets.ts) 在 Source 缓存之后调用 [scripts/native-row-slice-assets.ts](scripts/native-row-slice-assets.ts)，合并同时间与透明度程序的兼容三片粒子行；条件不匹配或图集容量不足时保留原包。

[scripts/pack-original-note-skins.ts](scripts/pack-original-note-skins.ts) 打包三套原生按键皮肤，保持更新前的原始图块规模；[完整资源生成器](scripts/build-original-assets.ts) 核对图集、材质、缩略图和实际图块引用。独立服务器和 [Worker 打包加载器](src/server/engineRom.ts) 共用引擎资源投影，并提供[切片引用识别](src/shared/nativeLaneClipReferences.ts)。它保留原始 ID 与不可用的兼容探针，使程序进入无切片裁剪路径。

长条图块按普通、按住及漏判的原始渐变取样，引导线使用独立的颜色与透明度。两类线身烘入原作默认透明度，Sonolus 的连接线选项继续作为绘制倍率。

[侧划生成器](scripts/build-native-side-flick-assets.ts) 读取三套样式的左／右移动发射器，通过与网页共用的粒子求值生成动画轨迹。简洁样式的侧划在发射帧锁定动画指定的粒子寿命，生成器用同一轨迹更新短驻留效果。固定轨迹按绘制顺序合并粒子组，并移除零面积或零透明度的图元。默认六轨和八轨右侧划将近场泛光烘进同一图元，控制边缘扩散范围，完成颜色响应拟合后压缩图集。[帧材质生成器](scripts/native-particles/sourceRigs.ts) 按简洁样式各自的 Great／Good／Bad 材质曲线重建对应光框，按参考画面校准默认样式的前沿、后沿及两侧亮度，并让两种侧滑的 Bad 底框共用中性灰材质。

[光晕生成器](scripts/build-native-source-glow-assets.ts) 消费独立引擎随附的采样工具输出。普通和上划沿用 B0，左右侧划在既有粒子层内合成光晕。采样工具用多种舞台色和黑白前景测量透射率，拟合每帧的一张光晕贴图。最终打包移除已被替换且无人引用的图块索引。

[散射粒子生成器](scripts/native-particles/scatteredLights.ts) 按简洁样式普通键、长键、连接键和上划的实际时间轴选择可见轨迹，以分段插值绘制亮芯、晕边和拖尾。图集共用程序生成的光斑，上划的散射光叠入同一粒子层。打包同步重建对应的短时上划资源。

[光墙生成器](scripts/native-particles/sourceRigs.ts) 读取各样式的墙面投影、材质颜色及动画曲线，合成到 P1 并保留独立的柱光。[连接点直绘材质](scripts/connect-wall-material-assets.ts) 校准简洁样式的单次命中淡出，沿用引擎现有的直绘图集。

[scripts/native-loop-frame-assets.ts](scripts/native-loop-frame-assets.ts) 按层校准默认与轻量长按期间的发光透明度，核对长条光框的重复时间轴，并以单周期版本替代完整重复的效果。

资源生成与 [打包兼容性检查](src/server/particleCompatibility.ts) 共用 [可选效果表](src/shared/nativeDrawCapabilities.ts)，按引擎回退能力允许指定效果缺省；短循环存在时才允许省略对应的长时间轴。每个粒子包限制为 2048 像素边长和 2 MiB 下载量。[打包入口](scripts/build-worker-assets.ts) 在加载生成器前关闭 esbuild 服务，打包失败时正常退出。

[src/protocol.ts](src/protocol.ts) 按客户端 User-Agent 在已支持版本中协商响应头；Worker 在共享缓存读取后设置版本，Node 预览使用同一实现。
