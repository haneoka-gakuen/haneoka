# D1 结构与迁移 · L2-2

上级：[地图](../L2.md)。

## 职责

[0059 迁移](migrations/0059_official_guest_accounts.sql)保存日服游客的一次创建身份、阶段／版本／nonce、期限和加密配置。注册结果先独立保存，验证失败不删除凭据；晚到创建结果按原身份保存一次，过期验证不能标记就绪。迁移本身不创建游戏账号。

[0060 迁移](migrations/0060_official_guest_requests.sql)按游客 ID 保存不可替换的加密原始注册配置，并绑定创建任务 nonce；先保存配置才允许领取注册任务。重启、环境配置变化和后续验证复用原配置，DO 队列不保存私有 Master 或游戏凭据。

[0061 迁移](migrations/0061_official_platform_sdk_identities.sql)按平台账号及配置的 SDK 身份范围保存长期 UID 绑定；有效登录租约可首次绑定或确认同一 UID，不能替换。更改名称、密码或会话缓存均保留绑定；迁移不解密旧缓存或推断历史 UID，由后续有效任务从匹配缓存或 SDK 结果建立。

[0062 迁移](migrations/0062_official_platform_sdk_owners.sql)按 SDK 身份范围与 UID 固定一个平台账号归属，SDK 认证后先确认归属再执行游戏登录。既有唯一身份回填所属账号；重复身份回填空归属并阻止新游戏登录，不自动挑选。归属独立于任务和会话期限，验证失败、改密及未知结果不转移归属。

[0063 迁移](migrations/0063_official_platform_sdk_resolution.sql)清除旧重复身份残留的会话，保留密码与身份绑定；空归属被明确确认时，触发器在同一事务中提高成员账号版本并清除 SDK／区服会话。所选账号需重新验证，其他别名保持排除；更新前的成员、版本与登录租约检查由平台存储负责，不提供已有归属的改派入口。

[0057 迁移](migrations/0057_official_platform_login_jobs.sql) 为国际服邮箱账号保存跨分区共用的登录任务租约、账号版本、期限和完成状态；任务不保存密码或令牌，角色会话仍加密保存在平台角色表。过期或版本失效的结果不更新角色。

[0056 迁移](migrations/0056_official_arena_finals.sql) 保留竞技场旧赛季定义、已采窗口和完整人数终榜目标；人口搜索提示与当前赛季分开持久化，窗口与人数成功后固定私有正文。两类终榜分别记录调度时间与窗口实际尝试时间，启动失败与窗口拒绝都可轮转。

[0055 迁移](migrations/0055_official_ranking_finals.sql) 保存活动单曲、总榜与积分榜的终榜目标、官方结束／聚合时间及首次截止后成功快照引用。待完成目标独立于当前活动目录，固定正文受历史清理保护。

[0054 迁移](migrations/0054_official_platform_accounts.sql) 保存国际服平台账号的加密密码及三个分区的独立角色初始化状态；密钥由 Worker secret 提供，初始状态为未初始化，保存成功不表示登录或建角成功。

[0058 迁移](migrations/0058_official_platform_sdk_sessions.sql) 保存平台账号共享的加密 SDK 会话及配置指纹；读写受当前登录租约和账号版本约束，修改密码时清除，独立于各分区的游戏凭据与就绪状态。

保存 Worker 的目标数据库结构和已提交的生产迁移；操作步骤由 [数据库 README](README.md) 唯一维护。

[0053 迁移](migrations/0053_official_ranking_daily.sql) 保存官方采集的逐服、逐榜、逐日成功快照引用，并从现存成功观测回填；活动榜、竞技场窗口、积分榜窗口和人数快照复用私有 R2 正文，即时窗口替换与定时清理保留被引用的对象。日界为日本时间，日快照不代表最终榜确认。

- [schema.sql](schema.sql)：新数据库目标结构。
- [migrations](migrations/)：按序应用的生产历史；已应用迁移不可重写。
- [数据库工具](../../scripts/database/L2-2.md)：本地快照、计划及应用，不替代部署迁移。

账户、社区、上传、审核、配队库存和事件历史等表由对应 Worker handler 使用；D1 访问经准备语句及请求会话。生产部署工作流可应用待执行迁移，不能把文档或源码合并等同无远端副作用。

[抽卡历史 handler](../gacha-history.ts) 使用[0032 迁移](migrations/0032_gacha_history_cloud.sql)中的 owner 私有白名单 collection、CAS revision 与刷新序号；游戏凭据不进入该文档。

结构变更同时维护新迁移和目标 schema，并检查读写者及旧版本兼容。原型重置迁移的历史特殊性见 README，不将其扩展为一般可删除数据的许可。本地计划、导出、行数据和数据库文件留在忽略目录。验证见 [开发导航](../../docs/DEV_GUIDE.md)。

[0037 迁移](migrations/0037_community_charts.sql) 保存社区谱面 head、独立的写入 version 与 published revision，以及版本素材引用、音频对象、点赞与可重试回收队列；撤回／删除推进 version 并收窄讨论访问，旧发布请求因此失效。谱面正文和编译后的 Sonolus LevelData 在上传 R2。

[0038 迁移](migrations/0038_community_chart_analysis.sql) 按谱面版本和模型版本保存服务端生成的分析。保存工程、读取列表及授权读取历史详情时生成，定时任务逐批补全当前公开版本；失败的空结果至少间隔一小时重试，成功结果不被失败覆盖。v4 重算期间，公开版本可暂用相同谱面版本的 v1–v3 基础统计，不使用旧推荐值；作者等级与模型推荐值分别保存。

[0039 迁移](migrations/0039_community_chart_media_snapshots.sql) 保存服务器素材快照、版本引用和来源索引；素材对象按内容去重，版本删除后才参与回收，不依赖正式资源 release 保留期限。

[0040 迁移](migrations/0040_official_ranking_cloud.sql) 为官方活动采集保存独立区服目录、高水位、挑战身份和观测索引；正文在私有榜单 R2，成功与失败观测共用数字游标，最新榜单只读取成功记录。重试按区服和 snapshot ID 去重，读取保留原始接收时间；旧 Moenotes 历史不迁移或重标。

[0041 迁移](migrations/0041_official_arena_rankings.sql) 为竞技场联赛保存官方名次窗口索引（赛季、乐队、起止名次、榜内人数），正文同样在私有榜单 R2；读取取对齐百名窗口的最新成功观测。

[0042 迁移](migrations/0042_official_arena_population.sql) 保存竞技场联赛完整阈值人数快照索引，并为联赛最新人数／窗口元数据建立索引，每窗口一条紧凑玩家 ID／位置索引使搜索命中只读取一份 R2；正文仍在私有 R2，公开 GET 不执行人口二分或游戏请求。

[0064 迁移](migrations/0064_official_observation_payload_gc.sql) 为四类官方观测索引的删除登记持久 R2 清理队列；触发器与索引删除同事务提交。[榜单存储](../official-ranking-store.ts) 在宽限期后复查索引与归档引用，R2 删除成功后才确认队列项；由所属区服采集 DO 与归档写入串行执行，失败保留待清理记录。

[0065 迁移](migrations/0065_official_account_removal.sql) 在托管账号删除时同步清除密码、角色／SDK 会话、登录任务与游客请求；保留区服／玩家 ID 墓碑以屏蔽旧配置中的同一玩家，游客 ID 墓碑阻止已删除创建请求重放。

[0066 迁移](migrations/0066_official_platform_login_batches.sql) 保存跨区服账号登录链的版本与期限互斥，以及迁入账号的稳定 SDK 设备身份；账号删除同事务清理两者。

[0067 迁移](migrations/0067_community_chart_impressions.sql) 按用户与谱面保存推荐首屏的曝光时间和次数，用于与帖子相同的已看降权；谱面身份跨发布版本保留，删除账号或谱面时级联清理。

[0068 迁移](migrations/0068_official_payload_batches.sql) 保存官方观测的短期正文与区域批次，暂存和观测索引同事务提交；为共享 R2 正文回收及逐观测归档引用增加索引。R2 批次写入成功后才删除对应暂存，两种旧／新正文格式由同一存储读取器兼容。

[0069 故事迁移](migrations/0069_community_stories.sql) 保存故事版本、素材授权、发布幂等收据和派生授权；源工程及运行工程位于上传 R2。

[0070 来源迁移](migrations/0070_story_revision_origins.sql) 按接收者与源修订保存授权，并为每个故事修订保存独立来源署名；原作回收后保留来源标识和署名。

[0071 故事上传范围](migrations/0071_story_upload_scope.sql) 标记作品内部的上传，并阻止将其绑定到普通帖子。

[0072 故事资源审核](migrations/0072_story_resource_reviews.sql) 保存按内容哈希共享的音频／SVG 审核记录，旧资源沿用既有状态；新资源在人工决定前只供私有创作使用。

[0073 故事资源边界](migrations/0073_story_resource_boundaries.sql) 阻止故事上传绑定歌单／谱面封面，也阻止已用于帖子或封面的附件改为故事专用上传。

[0074 故事自动检查](migrations/0074_story_resource_automatic_checks.sql) 保存音频／SVG 的队列任务、租约、重试、策略版本与模型结果；人工复核只包含自动检查需要介入的资源。
[0075 迁移](migrations/0075_official_storage_maintenance.sql) 保存逐服存储扫描租约／游标、压缩进度和回收计数，并为排名元数据的物理正文引用建立索引。新增退役时钟触发器按共享正文最后一次成员删除刷新宽限期，已有清理队列在首次启用时重新获得五分钟保护；重复应用不重置扫描状态或初始化时刻。
